# トレーサビリティCSV ファイル命名規則

`data/raw/traceability/` 配下の設備トレーサビリティCSVの命名規則をまとめる。
自動収集処理（[first_design.md](first_design.md) の「1. 複数の設備データファイルからデータを集計する」）で、
ファイル名から設備ID・年月を抽出する前提となる。

## 1. 命名フォーマット

```
<equipment_id>_<year-month>.csv
```

- 例: `EQ-01_2026-01.csv`
- 区切り文字: 設備IDと年月の間は **アンダースコア `_`**
- 拡張子: `.csv`

### 構成要素

| 要素 | 位置 | 形式 | 例 | 説明 |
|------|------|------|------|------|
| 設備ID | 先頭 | `EQ-NN`（`EQ-` + 2桁ゼロ埋め） | `EQ-01` | 設備を一意に識別する。ファイル内の `equipment_id` 列と一致 |
| 年月 | 末尾 | `YYYY-MM`（ハイフン区切り） | `2026-01` | 加工年月。ファイル内の `process_month` 列と一致 |

## 2. 設備ID と設備名の対応

ファイル名には設備IDのみが入り、設備名（`equipment_name` 列）は下表の通り対応する。
※ この対応は現行データ（全ファイル）で一貫していることを確認済み。

| 設備ID | 設備名 |
|--------|--------|
| EQ-01 | 圧入 |
| EQ-02 | 締結 |
| EQ-03 | 塗布 |
| EQ-04 | 溶接 |
| EQ-05 | 検査 |

## 4. CSVスキーマ（参考）

全ファイルで共通のヘッダーを持つ。

| 列名 | 例 | 備考 |
|------|------|------|
| `vin` | `VIN0000000` | 車台番号。結合キー |
| `equipment_id` | `EQ-01` | 設備ID。**ファイル名の設備IDと一致** |
| `equipment_name` | `圧入` | 設備名（第2章の対応） |
| `plant_code` | `P01` | 工場コード |
| `line_code` | `L-A` / `L-B` | ラインコード |
| `process_month` | `2026-01` | 加工年月。**ファイル名の年月と一致** |
| `operator` | `op_suzuki` | 作業者 |
| `lot_no` | `LOT-2026-01-13` | ロット番号 |
| `in_ts` | `2026-01-05 11:17:58` | 工程開始日時 |
| `out_ts` | `2026-01-05 11:18:42` | 工程終了日時 |
| `cycle_time_sec` | `44.2` | サイクルタイム（秒） |
| `judgment` | `OK` / `NG` | 判定結果 |

## 5. パース用の推奨正規表現

```python
import re

# ファイル名（例: "EQ-01_2026-01.csv"）から設備IDと年月を抽出
PATTERN = re.compile(r"^(?P<equipment_id>EQ-\d{2})_(?P<year_month>\d{4}-\d{2})\.csv$")

m = PATTERN.match(path.name)
if m is None:
    # 命名規則に合わないファイル → 除外してログ出力（first_design.md「異常ファイルの除外・ログ化」）
    ...
else:
    equipment_id = m.group("equipment_id")   # "EQ-01"
    year_month = m.group("year_month")        # "2026-01"
```

## 6. 運用上の注意・整合性ルール

- **ファイル名 vs 中身**: ファイル名の設備IDは `equipment_id` 列、年月は `process_month` 列と一致する。
  取り込み時に突合し、不一致ならエラーとしてログ化することを推奨。
- **ゼロ埋め**: 設備IDは2桁固定（`EQ-1` ではなく `EQ-01`）。月も2桁固定（`2026-1` ではなく `2026-01`）。
- **区切り**: 設備IDと年月の区切りは `_`、年月内のみ `-`。混同しないこと。
- **設備追加時**: `EQ-06` 以降を追加する場合は第2章の設備名対応表も更新する。
